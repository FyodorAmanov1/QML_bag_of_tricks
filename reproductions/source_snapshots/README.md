# Historical CLI provenance

`__main__.py.upstream` preserves the research CLI used for the archived runs,
before the public unified `project` routing was added. Auditors verify this
snapshot against the original reports' hashes, allowing only LF/CRLF spelling.
All other recorded numerical source files are still checked in place.

Current CLI behavior is covered by command parity and numerical/workflow tests.
The historical reports and their hashes have not been rewritten, and this
snapshot is not imported or executed as current application code.

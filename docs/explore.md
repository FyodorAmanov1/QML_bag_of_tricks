# Explore the documentation

Every guide is linked below, grouped by purpose. Start with a route, or jump
straight to the technical methods. You do not need search to discover the library.

| I want to… | Start here |
|---|---|
| Read circuit mathematics and native SDK implementations | [All circuit strategies](#strategies) · [Method selector](method_selector.md) |
| Build, train and evaluate a model | [Learning workflows](#learning) · [Model APIs](use_cases/models.md) |
| Reproduce a published application | [Paper reproductions](reproductions/index.md) · [Complete comparisons](reproductions/results.md) |
| Find an application for my project | [Published use cases](use_cases/index.md) · [Why QML?](why_qml.md) |
| Give the repository to a coding agent | [Copyable project briefs and setup](agents.md) |
| Follow a complete worked example | [Executed walkthroughs](tutorials.md) |

Each strategy guide states its mathematical contract, assumptions, implementation
scope and use cases, with Qiskit, PennyLane and Cirq source links. Published
guarantees, reduced demonstrations and local benchmark results remain distinct.

The directory below is assembled from the site's navigation at build time, so
new documentation pages appear automatically.
